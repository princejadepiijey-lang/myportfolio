I developed a prototype of a Registrar Document Request and Tracking System for CARD-MRI Development Institute (CMDI) to make requesting and tracking academic documents more convenient for students and the Registrar's Office. My contribution was developing the system's interface and features, including student and registrar login, account registration, student dashboards, document requests, and request status tracking. I organized the system by creating forms, designing the dashboard, adding different document request options, and allowing registrar staff to update request statuses and provide notes. I used HTML, CSS, JavaScript, browser local storage, and AI assistance during development. As a result, I created a working web-based prototype where students can submit document requests and monitor their progress, while registrars can manage requests and export records as CSV files. Through this project, I learned how different web technologies work together to create a useful information system. I also learned that data security is important, and I would improve the project by adding a secure database, stronger authentication, and a proper file-upload feature before using it in a real school environment.
